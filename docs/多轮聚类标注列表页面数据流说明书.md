# 多轮聚类标注列表页面 - 数据流说明书

## 1. 概述

本文档描述**多轮聚类标注列表页面**（`/multi-clustering`）中各操作的数据流转情况，包括页面加载、启动新轮聚类、跳过聚类等操作对底层存储的影响。

---

## 2. 涉及的数据存储

| 存储文件 | 路径 | 说明 |
|----------|------|------|
| round_history.json | `bussiness/datahome/{dataset}/multi_clustering/round_history.json` | 轮次历史记录 |
| hog_clusters.json | `bussiness/datahome/{dataset}/multi_clustering/rounds/round_N/hog_clusters.json` | 聚类结果（字符分组） |
| labels.json | `bussiness/datahome/{dataset}/multi_clustering/rounds/round_N/labels.json` | 聚类标注状态 |
| round_info.json | `bussiness/datahome/{dataset}/multi_clustering/rounds/round_N/round_info.json` | 轮次元信息 |
| all_chars.json | `bussiness/datahome/{dataset}/multi_clustering/char_pool/all_chars.json` | 字符池（status, label, labeled_round） |
| unlabeled.json | `bussiness/datahome/{dataset}/multi_clustering/char_pool/unlabeled.json` | 未标注字符列表 |
| labeled.json | `bussiness/datahome/{dataset}/multi_clustering/char_pool/labeled.json` | 已标注字符列表 |
| pre_labels.json | `bussiness/datahome/{dataset}/pre_labels.json` | OCR 预测结果 |
| prelabel_status.json | `bussiness/datahome/{dataset}/.meta/prelabel_status.json` | 预标注状态（confirmed/skipped/pending） |
| unified_labels.json | `bussiness/datahome/{dataset}/unified_labels.json` | 统一标注数据 |

## 3. 页面加载 - 数据读取流

### 3.1 触发方式

- 页面挂载（`onMounted`）
- 点击"刷新数据"按钮

### 3.2 数据流图

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    列表页面 - 加载数据                                   │
│                                                                         │
│  页面挂载 / 点击刷新                                                     │
└──────────────────────────────┬──────────────────────────────────────────┘
                               │
                    ┌──────────┼──────────┐
                    ▼          ▼          ▼
┌──────────────────────┐ ┌──────────────┐ ┌──────────────────────┐
│  GET /api/mc/        │ │ GET /api/mc/ │ │ GET /api/mc/         │
│  char-pool           │ │ rounds       │ │ rounds/{round}/      │
│                      │ │              │ │ clusters             │
│  读取:               │ │ 读取:        │ │ 读取:                │
│  all_chars.json      │ │ round_       │ │ hog_clusters.json    │
│  → total/labeled/    │ │ history.json │ │ + labels.json        │
│    unlabeled 统计    │ │              │ │ → 聚类列表           │
└──────────────────────┘ └──────────────┘ └──────────────────────┘
                                                    │
                                                    ▼
                               ┌──────────────────────────────────┐
                               │  GET /api/mc/rounds/{round}      │
                               │  读取:                           │
                               │  hog_clusters.json (聚类数/字符数)│
                               │  → round_info 元信息              │
                               └──────────────────────────────────┘
```

### 3.3 各接口读取的文件

| API 接口 | 读取文件 | 返回数据 |
|----------|----------|----------|
| `GET /api/mc/char-pool` | `all_chars.json`、`unlabeled.json`、`labeled.json` | `{ total, labeled, unlabeled }` |
| `GET /api/mc/rounds` | `round_history.json` | `{ rounds: [{ round, date, data_source, algorithm, ... }] }` |
| `GET /api/mc/rounds/{round}` | `hog_clusters.json` | `{ round, total_clusters, total_chars, progress }` |
| `GET /api/mc/rounds/{round}/clusters` | `hog_clusters.json` + `labels.json` | `{ clusters: [{ cluster_id, char_count, labeled_count, status, char, char_counts }] }` |

### 3.4 聚类列表数据组装

```
hog_clusters.json                    labels.json
┌──────────────────────┐            ┌──────────────────────────┐
│ clusters: {          │            │ labels: {                │
│   "1": [             │            │   "1": {                 │
│     {char_id: "x1"}, │  ──合并──▶ │     status: "labeled",   │
│     {char_id: "x2"}  │            │     char: "敦",          │
│   ],                 │            │     char_labels: {       │
│   "2": [...]         │            │       "0": {char:"敦"},  │
│ }                    │            │       "1": {char:"敦"}   │
└──────────────────────┘            │     }                    │
                                    │   }                      │
                                    │ }                        │
                                    └──────────────────────────┘

→ 聚类列表项:
{
  cluster_id: "1",
  char_count: 2,           ← len(hog_clusters.clusters["1"])
  labeled_count: 2,        ← 遍历 chars，排除 skipped 后有 char_labels 的数量
  skipped_count: 0,         ← 遍历 chars，all_chars 中 status=skipped 的数量
  remaining_count: 0,       ← char_count - labeled_count - skipped_count
  status: "labeled",       ← 动态计算: 全标注→labeled, 全跳过→skipped, 部分→partial, 无→unlabeled
  char: "敦",              ← labels["1"].char
  char_counts: {"敦": 2}   ← 统计 char_labels 中各汉字数量（排除 skipped）
}
```

## 4. 操作一：启动新轮聚类

### 4.1 触发方式

- 配置参数后点击"启动新轮聚类"按钮

### 4.2 调用链

```
前端 → POST /api/mc/rounds
     → MultiClusteringManager.start_new_round(params)
```

### 4.3 数据流图

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    列表页面 - 启动新轮聚类                               │
│                                                                         │
│  用户配置参数 → 点击 [启动新轮聚类]                                      │
│  参数: data_source, method, min_cluster_size, ...                        │
└──────────────────────────────┬──────────────────────────────────────────┘
                               │
                               ▼
┌──────────────────────────────────────────────────────────────────────────┐
│  MultiClusteringManager.start_new_round()                                │
│                                                                          │
│  ① 获取字符列表                                                          │
│     ├── data_source="unlabeled" → _get_unlabeled_char_ids()             │
│     │   读取: unlabeled.json → char_ids                                 │
│     └── data_source="low_confidence" → _get_low_confidence_char_ids()   │
│         读取: pre_labels.json → 过滤 confidence < threshold 的字符       │
│         排除: labeled.json(已标注) + all_chars.json(已跳过)              │
│               + prelabel_status.json(已确认)                             │
│                                                                          │
│  ② 提取 HOG 特征                                                         │
│     读取: pdf_chars/{char_id}.png → HOG 特征向量                        │
│                                                                          │
│  ③ 执行聚类算法                                                          │
│     ├── HDBSCAN: cosine距离矩阵 → HDBSCAN聚类                           │
│     └── KMeans: 特征矩阵 → KMeans聚类                                   │
│     过滤噪声点 (label=-1)                                                │
│     拆分超大类 (超过 max_cluster_size)                                    │
│     聚类内部按相似度排序                                                  │
│                                                                          │
│  ④ 创建轮次目录                                                          │
│     mkdir: rounds/round_{N}/                                             │
│                                                                          │
│  ⑤ 保存聚类结果                                                          │
│     写入: rounds/round_{N}/hog_clusters.json                            │
│     {                                                                    │
│       version, round, data_source, algorithm,                            │
│       n_clusters, total_chars, created_at,                               │
│       clusters: { cluster_id: [{char_id, line_name, ...}] },            │
│       params: { min_cluster_size, min_samples, max_cluster_size },      │
│       data_source_params: { confidence_threshold }                       │
│     }                                                                    │
│                                                                          │
│  ⑥ 初始化标注文件                                                        │
│     写入: rounds/round_{N}/labels.json                                  │
│     {                                                                    │
│       version, round, created_at,                                        │
│       labels: {                                                          │
│         cluster_id: { char: null, status: "unlabeled",                  │
│                       char_labels: {} }                                  │
│       }                                                                  │
│     }                                                                    │
│                                                                          │
│  ⑦ 更新轮次历史                                                          │
│     写入: round_history.json                                             │
│     rounds: [..., { round, date, data_source, algorithm,                 │
│                      n_clusters, total_chars, description }]             │
│                                                                          │
│  ⑧ 返回新轮次号                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

### 4.4 操作后各系统状态

| 存储文件 | 变更 | 说明 |
|----------|------|------|
| `rounds/round_N/` | 新建目录 | 新轮次目录 |
| `rounds/round_N/hog_clusters.json` | 新建 | 聚类结果 |
| `rounds/round_N/labels.json` | 新建 | 初始标注（全部 unlabeled） |
| `round_history.json` | 追加记录 | 新增轮次历史条目 |
| `char_pool/unlabeled.json` | 无变更 | 字符池在启动轮次时不移除字符 |
| `char_pool/all_chars.json` | 无变更 | 字符状态不变 |

> 注意：启动新轮次聚类**不会**修改字符池状态，字符池的变更发生在标注/跳过操作时。

## 5. 操作二：跳过聚类

### 5.1 触发方式

- 点击聚类列表中的"跳过"按钮

### 5.2 调用链

```
前端 → POST /api/mc/rounds/{round}/clusters/{cluster_id}/skip
     → MultiClusteringManager.skip_cluster(round_num, cluster_id)
     → _sync_skip_to_all(char_ids, round_num)
```

### 5.3 数据流图

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    列表页面 - 跳过聚类                                   │
│                                                                         │
│  用户点击 [跳过] → round=2, cluster_id=45, 包含 N 个字符                 │
└──────────────────────────────┬──────────────────────────────────────────┘
                               │
                               ▼
┌──────────────────────────────────────────────────────────────────────────┐
│  MultiClusteringManager.skip_cluster()                                   │
│                                                                          │
│  ① round_N/labels.json                                                   │
│     labels: { "45": { status: "skipped", skipped_at: "..." } }          │
│                                                                          │
│  ② 收集该聚类的所有字符ID                                                │
│     读取: hog_clusters.json → clusters["45"] → [char_id1, char_id2, ...]│
│                                                                          │
│  ③ _sync_skip_to_all(char_ids, round_num)                               │
│     ├── CharPool.batch_mark_as_skipped(char_ids, round_num)             │
│     │   all_chars.json: status → "skipped"                               │
│     │   unlabeled.json: 移除这些 char_id                                 │
│     │                                                                    │
│     ├── _update_prelabels_status(char_ids, "skipped")                   │
│     │   pre_labels.json: status → "skipped"                              │
│     │                                                                    │
│     ├── DataStore.batch_skip_prelabels(char_ids)                        │
│     │   prelabel_status.json: status → "skipped"                        │
│     │   label_history.json: 添加跳过记录                                  │
│     │   update_unified_label(): unified_labels: skipped                  │
│     │   _sync_to_char_pool_skipped(): all_chars: skipped                │
│     │   _sync_skip_to_multi_clustering(): 遍历所有轮次 labels: skipped  │
│     │                                                                    │
│     └── _update_unified_labels_status(char_ids, "skipped")              │
│         unified_labels.json: status → "skipped"                          │
└──────────────────────────────────────────────────────────────────────────┘
```

### 5.4 操作后各系统状态

| 存储文件 | 字段 | 值 | 说明 |
|----------|------|-----|------|
| round labels.json | status | `skipped` | ✅ 聚类状态已更新 |
| round labels.json | skipped_at | ISO时间 | ✅ 记录跳过时间 |
| all_chars.json | status | `skipped` | ✅ 所有字符已同步 |
| unlabeled.json | char_ids | 已移除 | ✅ 字符不再待标注 |
| pre_labels.json | status | `skipped` | ✅ OCR 系统已同步 |
| prelabel_status.json | status | `skipped` | ✅ 预标注系统已同步 |
| unified_labels.json | status | `skipped` | ✅ 统一标注已同步 |
| 其他轮次 labels.json | char_labels | skipped | ✅ 遍历所有轮次同步 |

### 5.5 页面刷新后看到的数据

| 元素 | 值 | 说明 |
|------|-----|------|
| 状态标签 | 红色"已跳过" | ✅ labels.json 状态已更新 |
| 字符数量 | 0/N | labeled_count 为 0 |
| 汉字列 | 无 | 无已标注汉字 |

## 8. 数据一致性总结

### 8.1 列表页操作同步矩阵

| 操作 | round_history | round labels | char_pool | prelabel_status | unified_labels | 其他轮次 labels |
|------|--------------|-------------|-----------|-----------------|----------------|----------------|
| 启动新轮聚类 | ✅ 追加 | ✅ 新建(unlabeled) | - | - | - | - |
| 跳过聚类 | - | ✅ skipped | ✅ skipped | ✅ skipped | ✅ skipped | ✅ 遍历同步 |
| 进入标注 | - | - | - | - | - | - |
| 切换轮次 | - | - | - | - | - | - |

### 8.2 跨轮次同步机制

> **重要**：跳过聚类操作通过 `_sync_skip_to_multi_clustering` 遍历所有轮次，确保同一字符在其他轮次中的标注状态也被标记为 skipped。

| 同步方法 | 功能 | 遍历行为 |
|----------|------|----------|
| `_sync_skip_to_multi_clustering()` | 同步跳过到多轮聚类 | 遍历所有 `round_N/` 目录，更新包含该 `char_id` 的聚类 |
| `_sync_to_multi_clustering()` | 同步标注到多轮聚类 | 同上（由标注页面的操作触发） |
| `_sync_reset_to_multi_clustering()` | 同步重置到多轮聚类 | 同上（由撤回操作触发） |

### 8.3 列表页数据刷新策略

| 操作 | 刷新范围 |
|------|----------|
| 启动新轮聚类 | 全部刷新（统计 + 轮次列表 + 聚类列表） |
| 跳过聚类 | 仅刷新当前轮次聚类列表 |
| 切换轮次 | 加载新轮次聚类列表 + 轮次详情 |
| 进入标注 | 不刷新（新标签页操作） |

### 8.4 历史问题与修复

| 问题 | 根因 | 修复 |
|------|------|------|
| 预标注确认后，列表页状态不更新 | `_sync_to_multi_clustering` 只更新第一个轮次 | 改为遍历所有轮次 |
| 跳过聚类后，其他轮次同字符状态不变 | `_sync_skip_to_multi_clustering` 只更新第一个轮次 | 改为遍历所有轮次 |
| 写入路径错误 | 使用 `round_dir / "labeling" / "labels.json"` | 修正为 `round_dir / "labels.json"` |
| 数据结构错误 | 直接操作 `labels` 顶层字典 | 改为 `labels_data["labels"]` 操作后保存 `labels_data` |
