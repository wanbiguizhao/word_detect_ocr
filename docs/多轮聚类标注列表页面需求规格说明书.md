# 多轮聚类标注列表页面 - 需求规格说明书

## 1. 页面概述

| 属性 | 值 |
|------|-----|
| **路由** | `/multi-clustering` |
| **用途** | 管理多轮聚类轮次、查看聚类列表、启动新轮次聚类、跳转标注 |
| **数据来源** | 字符池 + 聚类轮次历史 + 各轮次聚类结果 |
| **核心组件** | `MultiClusteringPage.vue` |
| **后端接口** | `/api/mc/*` |

## 5. 聚类参数配置面板

### 5.1 面板样式

| 属性 | 值 |
|------|-----|
| 组件 | `a-collapse`，默认展开 |
| 面板头 | "聚类参数配置"，加粗，浅灰背景 |
| 边框 | `1px solid #e8e8e8`，圆角 `8px` |

### 5.2 数据源选择

| 选项 | 值 | 说明 | 状态 |
|------|-----|------|------|
| 未标注汉字 | `unlabeled` | 对尚未标注的汉字图片进行聚类，发现新的汉字类别 | ✅ 可用 |
| 低置信度预测 | `low_confidence` | 对OCR预测置信度较低且未标记的图片进行聚类审查 | ✅ 可用 |
| 已标注离群检测 | `outlier` | 检测已标注数据中可能的标注错误 | ❌ 禁用（即将支持） |

选择数据源后，下方显示对应提示文字。

### 5.3 低置信度特有参数

| 参数 | 类型 | 范围 | 步长 | 默认值 | 说明 |
|------|------|------|------|--------|------|
| 置信度阈值 | 滑块 | 0.1 - 0.95 | 0.05 | 0.7 | 只聚类置信度低于此值且未标记的图片 |

标记点：`{ 0.1: '0.1', 0.5: '0.5', 0.7: '0.7', 0.95: '0.95' }`

**低置信度筛选条件**（必须同时满足）：
1. `confidence < confidence_threshold`（置信度低于阈值）
2. 不在 `labeled.json` 中（未标注）
3. 不在 `all_chars.json` 的 skipped 状态中（未跳过）
4. 不在 `prelabel_status.json` 的 confirmed 状态中（未在预标注页面确认过）

### 5.4 聚类方法参数

#### HDBSCAN 参数

| 参数 | 类型 | 范围 | 默认值 | 说明 |
|------|------|------|--------|------|
| 最小聚类大小 | 数字输入 | 3 - 50 | 5 | HDBSCAN 最小聚类大小 |
| 核心点样本数 | 数字输入 | 1 - 20 | 2 | HDBSCAN 核心点样本数 |
| 最大聚类大小 | 数字输入 | 10 - 200 | 100 | HDBSCAN 最大聚类大小 |

#### KMeans 参数

| 参数 | 类型 | 范围 | 默认值 | 说明 |
|------|------|------|--------|------|
| 目标聚类数 | 数字输入 | 2 - 100 | 20 | KMeans 目标聚类数 |

## 9. 聚类列表表格

### 9.1 表格配置

| 属性 | 值 |
|------|-----|
| 组件 | `a-table` |
| 行键 | `cluster_id` |
| 边框 | 有 |
| 分页 | 每页 20 条 |

### 9.2 列定义

| 列名 | 字段 | 宽度 | 说明 |
|------|------|------|------|
| 聚类ID | `cluster_id` | 100px | 聚类编号 |
| 状态 | - | 100px | 标签显示，颜色区分 |
| 汉字 | - | 200px | 已标注汉字及数量 |
| 字符数量 | - | 120px | 已标注/总数 |
| 操作 | - | 150px | 标注按钮 + 跳过按钮 |

### 9.3 状态列

状态根据聚类内字符的实际状态动态计算，而非仅依赖 labels.json 中的静态值：

| 状态 | 标签文字 | 标签颜色 | 计算规则 |
|------|----------|----------|----------|
| `labeled` | 已标注 | 绿色 `green` | 所有字符均已标注（剩余=0，跳过=0） |
| `skipped` | 已跳过 | 红色 `red` | 所有字符均已跳过（剩余=0，标注=0） |
| `partial` | 部分标注 | 橙色 `orange` | 存在已标注或已跳过的字符，但仍有剩余 |
| `unlabeled`（默认） | 未标注 | 默认灰色 `default` | 无任何已标注或已跳过的字符 |

### 9.4 汉字列

- 有已标注汉字时：显示 `汉字(数量)` 标签，蓝色背景 `#f0f5ff`，蓝色文字 `#1890ff`
- 无已标注汉字时：显示聚类主要字符 `char` 或 `?`

### 9.5 字符数量列

- 显示格式：`已标注数/已跳过数/总字符数`，如 `3/1/5`
- hover 时展示 tooltip 详细分解：`已标注 3 · 已跳过 1 · 剩余 1`
- 特殊情况：
  - 全部已标注：`5/0/5`
  - 全部跳过：`0/5/5`
  - 未处理：`0/0/5`

### 9.6 操作列

| 按钮 | 条件 | 功能 |
|------|------|------|
| 标注 | 非当前标注中 | 蓝色主按钮，新标签页打开标注页 |
| 标注中 | 当前正在标注 | 黄色按钮（`#faad14`），新标签页打开 |
| 跳过 | 始终 | 红色危险按钮，跳过整个聚类 |

## 11. 操作行为

### 11.1 启动新轮聚类

| 步骤 | 说明 |
|------|------|
| 1. 配置参数 | 选择数据源、聚类方法、调整参数 |
| 2. 输入描述 | 可选，默认"第N轮聚类" |
| 3. 点击启动 | 按钮进入 loading 状态 |
| 4. 调用接口 | `POST /api/mc/rounds` |
| 5. 成功 | `alert` 提示轮次号和数据源 |
| 6. 失败 | `alert` 显示错误信息 |
| 7. 刷新 | 自动刷新统计数据和轮次列表 |

### 11.2 跳过聚类

| 步骤 | 说明 |
|------|------|
| 1. 点击跳过 | 表格操作列的红色跳过按钮 |
| 2. 调用接口 | `POST /api/mc/rounds/{round}/clusters/{cluster_id}/skip` |
| 3. 刷新 | 自动刷新当前轮次聚类列表 |

### 11.3 进入标注

| 步骤 | 说明 |
|------|------|
| 1. 点击标注 | 新标签页打开 `/mc-label/{round}/{cluster_id}` |
| 2. 记录状态 | `activeClusterId` 标记当前标注的聚类 |

## 12. API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/mc/char-pool` | GET | 获取字符池统计 |
| `/api/mc/rounds` | GET | 获取所有轮次列表 |
| `/api/mc/rounds` | POST | 启动新一轮聚类 |
| `/api/mc/rounds/{round_num}` | GET | 获取轮次详情 |
| `/api/mc/rounds/{round_num}/clusters` | GET | 获取轮次聚类列表 |
| `/api/mc/rounds/{round_num}/clusters/{cluster_id}/skip` | POST | 跳过整个聚类 |

## 14. 数据一致性

### 14.1 启动新轮聚类

| 影响数据 | 变更 |
|----------|------|
| `rounds/round_N/` | 新建轮次目录 |
| `rounds/round_N/hog_clusters.json` | 聚类结果 |
| `rounds/round_N/labels.json` | 初始化标注文件 |
| `rounds/round_N/round_info.json` | 轮次元信息 |
| `char_pool/unlabeled.json` | 移除已被聚类的字符 |
| `char_pool/all_chars.json` | 更新字符的 `current_round` |

### 14.2 跳过聚类

| 影响数据 | 变更 |
|----------|------|
| `rounds/round_N/labels.json` | 聚类状态 → `skipped` |
| `char_pool/all_chars.json` | 字符状态 → `skipped` |
| `prelabel_status.json` | 字符状态 → `skipped` |
| `unified_labels.json` | 字符状态 → `skipped` |
| `pre_labels.json` | 字符状态 → `skipped` |

### 14.3 跨轮次同步

预标注页面或标注页面的操作会通过 `_sync_to_multi_clustering` 等方法**遍历所有轮次**同步更新，确保列表页显示的状态与实际一致。
