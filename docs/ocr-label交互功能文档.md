# OCR标注页面交互功能文档

## 1. 页面概述

**页面路径**: `/ocr-label/{clusterId}`

**页面功能**: 聚类标注页面，用于对聚类中的字符图片进行标注，支持单选、框选、批量标注等多种交互方式。

## 3. 交互功能详细说明

### 3.1 图片选择交互

#### 3.1.1 单选模式
- **触发方式**: 点击图片卡片
- **交互逻辑**:
  - 如果图片未被选中 → 添加到选中列表
  - 如果图片已被选中 → 从选中列表移除
- **样式变化**:
  ```css
  /* 默认状态 */
  .image-card {
    border: 2px solid #e8e8e8;
    background: #fff;
  }
  
  /* 鼠标悬停 */
  .image-card:hover {
    border-color: #1890ff;
  }
  
  /* 选中状态 */
  .image-card.selected {
    border: 3px dashed #1890ff;
    background: #e6f7ff;
    box-shadow: 0 0 12px rgba(24, 144, 255, 0.4);
    transform: scale(1.02);
  }
  ```

#### 3.1.2 框选模式
- **触发方式**: 在空白区域按住鼠标左键拖拽
- **交互逻辑**:
  1. `mousedown` → 记录起始坐标，进入选择状态
  2. `mousemove` → 更新选择框位置和大小
  3. `mouseup/mouseleave` → 结束选择，将框内图片添加到选中列表
- **样式变化**:
  ```css
  .selection-box {
    position: absolute;
    border: 2px dashed #1890ff;
    background: rgba(24, 144, 255, 0.1);
    pointer-events: none;
    z-index: 100;
  }
  ```
- **框选算法**: 图片卡片完全在选择框内才被选中

#### 3.1.3 全选/清除选择
- **全选**: 点击"全选"按钮 → 将所有图片添加到选中列表
- **清除选择**: 点击"清除选择"按钮 → 清空选中列表

### 3.2 标注输入交互

#### 3.2.1 单个标注
- **触发方式**: 在图片下方的输入框中输入汉字
- **交互逻辑**:
  - 输入内容 → 保存到 `pendingLabels` 对象（临时存储）
  - 失去焦点 → 保留在临时状态，等待批量保存
- **样式变化**:
  ```css
  /* 待保存状态 */
  .image-card.pending {
    border-color: #faad14;
    background: #fffbe6;
    border-style: dashed;
    animation: pending-pulse 1.5s ease-in-out infinite;
  }
  
  @keyframes pending-pulse {
    0%, 100% { box-shadow: 0 0 0 0 rgba(250, 173, 20, 0.4); }
    50% { box-shadow: 0 0 0 6px rgba(250, 173, 20, 0); }
  }
  ```

#### 3.2.2 批量标注
- **触发方式**:
  1. 选中多个图片
  2. 在"批量标注"输入框中输入汉字
  3. 点击"保存全部"按钮
- **交互逻辑**: 将输入的汉字应用到所有选中的未标注图片

### 3.3 二次聚类推荐交互

#### 3.3.1 推荐模式切换
- **全局锚点**: 使用所有已标注数据作为锚点进行推荐
- **当前聚类锚点**: 仅使用当前聚类的已标注数据作为锚点
- **自动切换**: 如果当前聚类已有标注，自动切换为"当前聚类锚点"

#### 3.3.2 推荐标签交互
- **显示内容**: 汉字 + 数量 + 平均相似度
- **交互方式**: 点击标签 → 加载该汉字的推荐图片
- **样式变化**:
  ```css
  /* 默认状态 */
  .recommend-tag {
    background: #52c41a;
    color: #fff;
  }
  
  /* 选中状态 */
  .recommend-tag[color="blue"] {
    background: #1890ff;
  }
  ```

#### 3.3.3 推荐图片交互
- **显示内容**: 图片 + 相似度百分比徽章
- **交互方式**:
  - 点击 → 切换选中状态
  - 右键 → 从推荐中移除
  - 拖拽框选 → 批量选择
- **样式变化**:
  ```css
  /* 默认状态 */
  .recommend-image-card {
    background: #e6f7ff;
    border: 2px solid #91d5ff;
  }
  
  /* 选中状态 */
  .recommend-image-card.selected {
    border-color: #1890ff;
    background: #bae7ff;
  }
  ```

#### 3.3.4 应用推荐标注
- **触发方式**: 点击"标注选中"按钮
- **交互逻辑**: 将选中的推荐图片批量标注为当前推荐汉字

### 3.4 右键上下文菜单

#### 3.4.1 行上下文查看
- **触发方式**: 右键点击图片卡片
- **交互逻辑**:
  1. 获取图片的行信息（line_name, col_start, col_end）
  2. 请求行图片
  3. 裁剪并高亮显示当前字符位置
  4. 弹出模态框显示
- **显示效果**:
  - 行图片居中显示
  - 当前字符位置用红色竖线标记
  - 左右各扩展50像素的上下文

### 3.5 聚类状态管理

#### 3.5.1 暂不标记
- **触发方式**: 点击"暂不标记"按钮
- **交互逻辑**:
  1. 弹出确认对话框
  2. 确认后发送请求标记聚类为"暂不标记"状态
  3. 跳转到聚类列表页面

#### 3.5.2 保存全部标注
- **触发方式**: 点击"保存全部"按钮
- **交互逻辑**:
  1. 收集所有待保存的标注（选中的批量标注 + 单个输入的标注）
  2. 发送批量保存请求
  3. 显示保存结果（新增汉字数量）
  4. 刷新页面

### 3.6 图片排序规则

图片按照以下规则自动排序：
1. **未标注图片在前，已标注图片在后**
2. **已标注图片按标注数量升序，数量相同按汉字字典序**
3. **选中的图片始终排在最前面**

```javascript
const displayImages = computed(() => {
  const sorted = [...images.value].sort((a, b) => {
    const aHasLabel = !!a.label
    const bHasLabel = !!b.label
    
    // 未标注在前
    if (aHasLabel && !bHasLabel) return 1
    if (!aHasLabel && bHasLabel) return -1
    
    // 已标注按数量和字典序
    if (aHasLabel && bHasLabel) {
      const aCount = labelCounts[a.label] || 0
      const bCount = labelCounts[b.label] || 0
      if (aCount !== bCount) return aCount - bCount
      return a.label.localeCompare(b.label)
    }
    
    return 0
  })
  
  // 选中的图片排在最前面
  if (selectedIndices.value.length > 0) {
    const selected = sorted.filter(img => selectedIndices.value.includes(img.index))
    const notSelected = sorted.filter(img => !selectedIndices.value.includes(img.index))
    return [...selected, ...notSelected]
  }
  
  return sorted
})
```

## 6. 数据流与状态管理

```
用户操作 → 响应式状态更新 → 样式变化 → 保存请求 → 后端更新

状态对象:
- images: 图片列表数据
- selectedIndices: 选中图片索引数组
- pendingLabels: 待保存标注 { [index]: char }
- batchChar: 批量标注输入内容
- recommendations: 推荐标签列表
- recommendImages: 推荐图片列表
- selectedRecommendIndices: 选中推荐图片索引
- isSelecting: 是否正在框选
- isRecommendSelecting: 是否正在框选推荐图片
```

## 7. API接口调用

| 接口 | 方法 | 作用 |
|------|------|------|
| `/api/clusters/{id}/images` | GET | 获取聚类图片列表 |
| `/api/cluster-labels` | GET | 获取聚类标注信息 |
| `/api/clusters/{id}/recommend` | GET | 获取推荐标签 |
| `/api/clusters/{id}/recommend/{char}` | GET | 获取推荐图片 |
| `/api/cluster-labels/batch-save` | POST | 批量保存标注 |
| `/api/clusters/{id}/skip` | POST | 标记聚类为暂不标注 |
| `/api/cluster-labels/save` | POST | 保存聚类别名 |
